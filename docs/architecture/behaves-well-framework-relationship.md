# Behaves Well Framework relationship

> Proposed canonical relationship document; inherited HTBW boundaries are accepted.
> Full public alignment: **REMEDIATION REQUIRED**. Reviewed 2026-11-07.

Home Steward applies the common Behaves Well governance architecture; it does not create an AI
framework or an eighth HTBW responsibility. Homes That Behave Well is the residential application
and evidence context. Human Trust is an outcome, not a component.

## Accepted HTBW responsibility mapping

The accepted [HTBW North Star](https://github.com/Homes-That-Behave-Well-LLC/homes_that_behave_well/blob/main/docs/architecture/north-star.md)
and [DL-131](https://github.com/Homes-That-Behave-Well-LLC/homes_that_behave_well/blob/main/docs/architecture/adr-home-steward-product-boundary.md)
control the following mapping:

1. **Foundation:** defines structure, Assets, People, Rooms, relationships, vocabulary, source
   references and capabilities. Home Steward consumes them; it never creates a competing authority.
2. **Stewardship:** represents what matters and requires care. Authorized knowledge may enrich an
   explanation/proposal; Home Steward cannot independently create, remove or satisfy an obligation.
3. **Identity:** supplies effective Person resolution. Data availability is not entitlement.
4. **Truth:** owns authoritative current/historical Home Facts. Retrieval, research and confident
   model output do not automatically become Truth.
5. **Continuity:** supplies applicable session, context, interaction history and experience continuity.
   Home Steward may contribute conversation without owning it.
6. **Operational Trust:** governs this request's access, disclosure, privacy, consent-policy,
   confirmation, authority and autonomy. Knowledge is not a shortcut around it.
7. **Concierge:** orchestrates appropriate behavior and may invoke Home Steward for an answer,
   uncertainty, candidate relationship or proposal. Execution remains governed through HTBW.

**Human Trust:** earned through restraint, provenance, locality, transparency, correction, visible
uncertainty and predictable behavior.

**Behavioral Governance / Decision Trace:** cross-cutting, with contributions from existing owners.
Home Steward provides minimal explainable evidence; it does not require indefinite raw prompt or
source retention, nor become the Trace owner.

## Publication discrepancy

Public evidence, read 2026-11-07:

- [Framework home](https://behaveswellframework.com/) describes "six framework layers".
- [Framework specification v1.0](https://behaveswellframework.com/specification), section
  "The Six Responsibilities", lists Truth, Identity, Operational Trust, Stewardship, Continuity,
  Concierge, without Foundation in that responsibility set.
- [HTBW public Framework page](https://www.homesthatbehavewell.com/framework) says "Six connected
  responsibilities".
- The accepted repository North Star requires seven, in Foundation -> Stewardship -> Identity ->
  Truth -> Continuity -> Operational Trust -> Concierge order.

These are not the same published responsibility set or order. This bootstrap **stops only the
assertion that the public/repository definitions are fully reconciled**. It preserves accepted HTBW
ownership and does not silently add Foundation to the public specification, remove it from HTBW,
interpret the mismatch as an accepted amendment, or self-decide which publication should change.

Owner disposition is tracked in [open questions](../governance/open-questions.md#public-framework-alignment)
and [bootstrap #1](https://github.com/Homes-That-Behave-Well-LLC/home_steward/issues/1), not a sixth issue.
No public website or accepted HTBW architecture was edited.
