## 5. Home Steward synthesis

Provide current HTBW path, current native HA path, expected simplification, retained governance,
affected documentation/code, migration risk, acceptance plan, Technical Debt reduction and new
obligations. Compare behavior/authority/privacy/degradation/performance, not code size alone.

A smaller implementation that loses meaningful intent, exceptions or Explainability is not a better
outcome. Technical Debt is an assessment lens, not a new model; reduced upkeep may trade against
vendor/version dependencies and recovery burden. No action or further evidence may be preferable.

## 14. Unavailable / degraded behavior
