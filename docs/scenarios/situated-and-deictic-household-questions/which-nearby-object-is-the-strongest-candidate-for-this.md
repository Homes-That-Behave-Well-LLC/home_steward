# Which nearby object is the strongest candidate for “this”?

Status: VISION — NOT YET ARCHITECTED

## Household question

Which nearby object is the strongest candidate for “this”?

## Why it matters

The nearest object may be an obvious candidate for 'this' while still being the wrong referent. The household wants useful distinctions among eligible candidates rather than a strongest-looking guess presented as identity. Confidence must reflect missing clues and competing interpretations, not simply physical proximity.
