# When does temporary access expire?

Status: VISION — NOT YET ARCHITECTED

## Household question

When does temporary access expire?

## Why it matters

Temporary access should be understandable without guessing from a visit ending or an account becoming quiet. The household wants the recorded expiry conditions and any uncertainty about their effective status. A scheduled end and evidence that permission actually ceased are different facts, especially when several sources report different times.
