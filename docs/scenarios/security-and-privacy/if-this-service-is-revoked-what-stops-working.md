# If this service is revoked, what stops working?

Status: VISION — NOT YET ARCHITECTED

## Household question

If this service is revoked, what stops working?

## Why it matters

Revoking a service can affect more than its most visible feature. The household wants to understand documented dependencies, preserved native behavior and uncertainties before any separately governed decision. Privacy improvement should not be assumed to justify losing an important care or accessibility outcome, and a prediction is not an observed outage.
