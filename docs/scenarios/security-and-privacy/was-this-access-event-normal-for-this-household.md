# Was this access event normal for this household?

Status: VISION — NOT YET ARCHITECTED

## Household question

Was this access event normal for this household?

## Why it matters

An unexpected access entry can be a legitimate visit, a changed routine or a record with missing context. A household wants to understand the comparison period and any explicitly recorded explanation before calling the event unusual. Familiarity should not turn into a presumption that the visitor is trustworthy or authorized.
