# Did the last update change external connections?

Status: VISION — NOT YET ARCHITECTED

## Household question

Did the last update change external connections?

## Why it matters

An update can change documented dependencies even when the visible household experience looks unchanged. The household wants to compare the relevant versions and understand whether outside connection expectations still match the installed configuration. Missing observation windows should be visible rather than mistaken for evidence that the update changed nothing.
