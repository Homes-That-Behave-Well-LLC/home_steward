# Which interactions depend on seeing a screen?

Status: VISION — NOT YET ARCHITECTED

## Household question

Which interactions depend on seeing a screen?

## Why it matters

A screen can be inaccessible because of vision, glare, distance, occupied hands or a device being unavailable. The household wants to know which tasks actually require visual information and whether another documented route remains usable. This inquiry should explore interaction assumptions without diagnosing sight or treating an interface's presence as proof that everyone can use it.
