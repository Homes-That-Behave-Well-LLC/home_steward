# How has this collection's documented value changed over time?

Status: VISION — NOT YET ARCHITECTED

## Household question

How has this collection's documented value changed over time?

## Why it matters

A household may want to understand how its collection's documented values changed across acquisition papers, appraisals and insurance schedules. Those numbers can reflect different purposes, dates, groupings and currencies rather than a consistent market-value history. A careful explanation could reveal the documentary pattern while keeping undocumented Assets and nonfinancial household significance from disappearing behind an apparently precise collection total.
