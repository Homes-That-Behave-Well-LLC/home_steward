# Which insured values differ materially from latest appraisals?

Status: VISION — NOT YET ARCHITECTED

## Household question

Which insured values differ materially from latest appraisals?

## Why it matters

A household may notice that an insured figure differs from an appraisal and want to understand the documentary mismatch. Different dates, valuation purposes, currencies or covered groupings can make direct comparison misleading. An explanation could prepare questions for qualified insurance and appraisal professionals without treating either number as current market value or deciding that the household is adequately or inadequately insured.
