# Environmental Quality

Navigation and scope guidance only; not an architecture contract or roadmap. Browse the [scenario-family map](../README.md).

## Purpose

Understand Room conditions, apparent changes and service-discussion evidence across permitted environmental sources.

## Relationship to HTBW

Truth retains supported measurements and indicators; Foundation holds declared requirements; Stewardship owns care evaluation and obligations. See the existing [HTBW boundary](../../architecture/htbw-boundary.md).

## Possible Home Steward extension

Compare authorized indoor/outdoor evidence and contextual changes while preserving units, windows, coverage and uncertainty. Any new source admission, representation, handoff or implementation is an OPEN ARCHITECTURAL QUESTION.

## Boundaries

Provider-derived indicators are not diagnoses or proof of mold. Correlation is not causation; no provider-algorithm recreation, generated universal limits, HVAC actions or health/life-safety guarantee.

Person/source/purpose/namespace/audience scope, household-controlled locality and source-derived lifecycle remain independent requirements. Potential evidence is not admitted access; knowledge is not action or disclosure authority. Source reports and inference are not automatic Truth; unknown is valid and correlation is not causation.
