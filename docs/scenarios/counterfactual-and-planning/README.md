# Counterfactual and Planning

Navigation and scope guidance only; not an architecture contract or roadmap. Browse the [scenario-family map](../README.md).

## Purpose

Explore conditional consequences of possible changes using known dependencies and explicit assumptions, without claiming perfect prediction.

## Relationship to HTBW

Actual configuration, Truth, relationships, obligations and acceptance stay HTBW-owned. A hypothetical state is never current Truth or an approved change. See the existing [HTBW boundary](../../architecture/htbw-boundary.md).

## Possible Home Steward extension

Explain supported dependency, locality, care and source-lifecycle implications of a hypothetical change. Any new source admission, representation, handoff or implementation is an OPEN ARCHITECTURAL QUESTION.

## Boundaries

No removal, substitution, relocation, revocation, purchasing or policy action follows from a question. Missing dependencies remain missing; independence, export and restoration claims need evidence.

Person/source/purpose/namespace/audience scope, household-controlled locality and source-derived lifecycle remain independent requirements. Potential evidence is not admitted access; knowledge is not action or disclosure authority. Source reports and inference are not automatic Truth; unknown is valid and correlation is not causation.

### Vision — Not Yet Architected

- [What stops working if Alexa is removed completely?](what-stops-working-if-alexa-is-removed-completely.md) — **VISION — NOT YET ARCHITECTED**. Removing an external voice ecosystem could affect several configured experiences differently.
- [What happens if the Internet is unavailable for three days?](what-happens-if-the-internet-is-unavailable-for-three-days.md) — **VISION — NOT YET ARCHITECTED**. A three-day outage raises duration-related questions beyond a brief connection loss, including known service expiry and extended care arrangements.
- [What changes if Sonos is replaced?](what-changes-if-sonos-is-replaced.md) — **VISION — NOT YET ARCHITECTED**. Replacing a speaker platform can affect configured response destinations, media experiences and household expectations beyond sound quality.
- [Which capabilities depend on this subscription?](which-capabilities-depend-on-this-subscription.md) — **VISION — NOT YET ARCHITECTED**. A subscription may support one outcome directly and merely enrich another.
- [What happens if this Asset moves to another room?](what-happens-if-this-asset-moves-to-another-room.md) — **VISION — NOT YET ARCHITECTED**. Moving an Asset can change environmental care, Room relationships and expected household experience without changing ownership or custody automatically.
- [What happens if we stop using this vendor?](what-happens-if-we-stop-using-this-vendor.md) — **VISION — NOT YET ARCHITECTED**. Ending a vendor relationship may remove support, external data or a particular service while leaving other functions intact.
- [What obligations would this proposed capability create?](what-obligations-would-this-proposed-capability-create.md) — **VISION — NOT YET ARCHITECTED**. A possible capability can add care, subscriptions, credentials, support work and privacy obligations even when the feature seems useful.
- [What information becomes unavailable if this connector is revoked?](what-information-becomes-unavailable-if-this-connector-is-revoked.md) — **VISION — NOT YET ARCHITECTED**. Revoking a connector can remove eligible retrieval and derived knowledge without deleting every authoritative original.
- [What breaks if this server disappears?](what-breaks-if-this-server-disappears.md) — **VISION — NOT YET ARCHITECTED**. Permanent server loss differs from asking which dependencies are currently recorded: recovery, unavailable configuration and known replacement constraints may matter.
- [What knowledge survives if Home Steward disappears?](what-knowledge-survives-if-home-steward-disappears.md) — **VISION — NOT YET ARCHITECTED**. Authoritative household documents and native HTBW knowledge should remain distinct from optional Home Steward-derived representations.
