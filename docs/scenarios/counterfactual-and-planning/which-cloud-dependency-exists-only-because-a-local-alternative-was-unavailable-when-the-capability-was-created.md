## Household question

Which cloud dependency exists only because a local alternative was unavailable when the capability was created?

## Why it matters

A cloud dependency may reflect an earlier technical limitation rather than an enduring household preference. The household wants its recorded reason distinguished from a convenient retrospective explanation. A later local option does not automatically remove the original governance concern or justify changing a capability the household still values.
