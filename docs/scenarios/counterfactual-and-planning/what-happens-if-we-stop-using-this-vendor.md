# What happens if we stop using this vendor?

Status: VISION — NOT YET ARCHITECTED

## Household question

What happens if we stop using this vendor?

## Why it matters

Ending a vendor relationship may remove support, external data or a particular service while leaving other functions intact. The household wants known consequences and uncertain obligations understood, without conflating cancellation with credential deletion, ownership transfer or complete local independence.

## Existing HTBW relationship

HTBW owns actual declared capabilities, dependencies, Asset relationships, governed configuration, obligations and Truth. A hypothetical state is not current Truth, an approved configuration, or acceptance of a change. Home Assistant and specialists retain their existing roles.

## Possible Home Steward extension

These are possible categories only, not admitted sources. Each requires independent Person/source/purpose/audience scope; derived information inherits sensitivity, household-controlled locality and source lifecycle.

No hypothetical question authorizes removal, relocation, revocation, purchase or configuration change. Manual alternatives and independent life-safety paths must remain distinct. Source reports and inference are not automatic Truth; unknown is a valid result. No silent cloud or source fallback.
