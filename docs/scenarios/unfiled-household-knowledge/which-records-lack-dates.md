# Which records lack dates?

Status: VISION — NOT YET ARCHITECTED

## Household question

Which records lack dates?

## Why it matters

Undated records can mislead a household about current care, ownership or coverage. The household wants the missing date visible without treating a download timestamp as the document's effective date or inventing chronology from where a file was stored.
