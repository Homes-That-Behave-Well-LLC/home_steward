# Which Assets lack baseline photographs?

Status: VISION — NOT YET ARCHITECTED

## Household question

Which Assets lack baseline photographs?

## Why it matters

A household may discover that familiar collection objects have no usable baseline photographs. That gap matters when later images raise questions about change, especially if available pictures are undated or show only selected views. Understanding the documentation gap could improve a professional discussion without assuming that a newly taken photograph reconstructs earlier condition or that inaccessible pictures do not exist.
