Status: VISION — NOT YET ARCHITECTED

## Household question

Does prior repair/treatment change the recommendation?

## Why it matters

A household may remember that an object was repaired but not what the treatment changed. Adhesives, coatings, lining or replacement components can complicate how broad guidance applies. Understanding the documented treatment context would help frame a useful conservator consultation, especially when the original material description no longer captures everything relevant to the object's condition.
