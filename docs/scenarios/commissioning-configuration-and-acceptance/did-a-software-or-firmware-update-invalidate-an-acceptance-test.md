# Did a software or firmware update invalidate an acceptance test?

Status: VISION — NOT YET ARCHITECTED

## Household question

Did a software or firmware update invalidate an acceptance test?

## Why it matters

An update can change what a test exercises without visibly breaking the Home. The household wants exact version and test applicability understood separately from whether the capability currently works. A later software date alone cannot prove that the prior acceptance test became invalid or that acceptance should be withdrawn.
