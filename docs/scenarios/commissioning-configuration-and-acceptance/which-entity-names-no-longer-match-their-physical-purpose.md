# Which entity names no longer match their physical purpose?

Status: VISION — NOT YET ARCHITECTED

## Household question

Which entity names no longer match their physical purpose?

## Why it matters

An entity name can preserve an old installation purpose after the underlying device or use changes. The household wants naming, configured meaning and physical function compared without treating a label as authoritative semantics. Renaming alone might hide rather than resolve an incorrect relationship.
