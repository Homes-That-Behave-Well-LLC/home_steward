# Does every configured room still have the correct voice-input and audio-output relationships?

Status: VISION — NOT YET ARCHITECTED

## Household question

Does every configured room still have the correct voice-input and audio-output relationships?

Related wording covered by this primary, without another file:

- Which microphones are associated with the wrong rooms?
- Which speakers or output devices are associated with the wrong rooms?

## Why it matters

A microphone associated with the wrong Room can misframe a request even when speech capture works. A speaker associated with the wrong Room can disclose an answer to a different audience even when audio playback works. The household wants both assignments reviewed independently across configured Rooms; co-location or a working input must not be taken as proof that output is correct.
