# Which manual fallbacks have never been tested?

Status: VISION — NOT YET ARCHITECTED

## Household question

Which manual fallbacks have never been tested?

## Why it matters

A fallback may be documented, actually exercised or still unproven under the relevant outage conditions. The household wants tested manual alternatives distinguished from document-only and never-exercised procedures, including which experiences lack qualifying evidence. A procedure tested in another context must not become an assurance that anyone can safely use it today.
