# Aging in Place and Care Awareness

Navigation and scope guidance only; not an architecture contract or roadmap. Browse the [scenario-family map](../README.md).

## Purpose

Preserve developed, person-authorized questions about changes in observations, personal baselines and careful caregiver or clinician summaries.

## Relationship to HTBW

People are not Assets. Stewardship owns declared care, Identity preserves Person scope, Truth owns supported Facts, and Operational Trust governs independent source and disclosure access. See the existing [HTBW boundary](../../architecture/htbw-boundary.md).

## Possible Home Steward extension

Compare eligible personal observations and contextual evidence, preserving source limitations and an observed personal baseline rather than generic medical normality. Any new source admission, representation, handoff or implementation is an OPEN ARCHITECTURAL QUESTION.

## Boundaries

No diagnosis, disease/fall prediction, treatment, medication-effect inference, clinical monitoring or medical-emergency judgment. Original wearable alerts are not strengthened or dismissed. No LLM critical path or automatic caregiver-notification mechanism.

Person/source/purpose/namespace/audience scope, household-controlled locality and source-derived lifecycle remain independent requirements. Potential evidence is not admitted access; knowledge is not action or disclosure authority. Source reports and inference are not automatic Truth; unknown is valid and correlation is not causation.
