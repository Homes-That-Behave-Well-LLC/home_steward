# Which kiosk capabilities still work if the kiosk VLAN cannot reach an external service?

Status: VISION — NOT YET ARCHITECTED

## Household question

Which kiosk capabilities still work if the kiosk VLAN cannot reach an external service?

## Why it matters

A kiosk can remain powered and reachable locally while an external capability is unavailable. The household wants its native local help, provider-dependent information and unknown outcomes distinguished rather than a single online/offline label. A display remaining visible is not proof that its controls or external data still work.
