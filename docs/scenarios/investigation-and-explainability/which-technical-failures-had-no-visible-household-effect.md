# Which technical failures had no visible household effect?

Status: VISION — NOT YET ARCHITECTED

## Household question

Which technical failures had no visible household effect?

## Why it matters

A technical failure can be contained by an existing fallback or affect a function nobody used during the interval. The household wants known failures without a visible household effect distinguished from failures whose effect was simply unobserved. Quiet operation should not erase technical evidence or create false reassurance about resilience.
