# If this VLAN is unavailable, which household experiences are affected?

Status: VISION — NOT YET ARCHITECTED

## Household question

If this VLAN is unavailable, which household experiences are affected?

## Why it matters

A VLAN becoming unavailable may affect only some household experiences, and devices in another segment may depend on services within it. The household wants evidenced consequences and independent alternatives distinguished from assumptions based on network membership. Loss of visibility into a segment is not proof every device there failed.

## Important boundary

Evidence categories are not source admission. Person/source/purpose/namespace/audience authorization remains independent before retrieval, combination and disclosure. One Person's grant is not another's; summaries retain the most restrictive applicable source constraints. USE != INGEST != DERIVE != RETAIN. Confirmation does not grant authority to retain, disclose or act. No shadow history or silent cloud/source fallback.
