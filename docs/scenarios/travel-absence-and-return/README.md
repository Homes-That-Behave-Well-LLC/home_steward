# Travel, Absence and Return

Navigation and scope guidance only; not an architecture contract or roadmap. Browse the [scenario-family map](../README.md).

## Purpose

Understand permitted preparation, existing obligations, absence-period evidence and return context without turning travel into surveillance.

## Relationship to HTBW

HTBW owns existing Home behavior, current/historical Truth, native Explainability and Stewardship. The developed away-history scenario remains the primary bounded absence narrative. See the existing [HTBW boundary](../../architecture/htbw-boundary.md).

## Possible Home Steward extension

Compare authorized travel windows, commitments, equipment evidence and existing arrangements. Any new source admission, representation, handoff or implementation is an OPEN ARCHITECTURAL QUESTION.

## Boundaries

Travel dates do not establish occupancy or authority. No automatic controls, itinerary disclosure, caretaker assignment or private-history collection; unavailable evidence remains unavailable.

Person/source/purpose/namespace/audience scope, household-controlled locality and source-derived lifecycle remain independent requirements. Potential evidence is not admitted access; knowledge is not action or disclosure authority. Source reports and inference are not automatic Truth; unknown is valid and correlation is not causation.

### Vision — Not Yet Architected

- [We're leaving Thursday. What should we think about before we go?](we-re-leaving-thursday-what-should-we-think-about-before-we-go.md) — **VISION — NOT YET ARCHITECTED**. Before a trip, the household wants to understand what its already-declared plans and Home-care requirements imply for the absence.
- [Is anything due while we're away?](is-anything-due-while-we-re-away.md) — **VISION — NOT YET ARCHITECTED**. Care obligations do not disappear when the household travels.
- [What deliveries or appointments overlap with the trip?](what-deliveries-or-appointments-overlap-with-the-trip.md) — **VISION — NOT YET ARCHITECTED**. An appointment or delivery can overlap with a planned absence even when neither source knows about the other.
- [What needs our attention now that we're home?](what-needs-our-attention-now-that-we-re-home.md) — **VISION — NOT YET ARCHITECTED**. Returning home creates a particular review context: existing due items may need attention, while newly reported changes may only need understanding.
- [Did any equipment behave differently while the house was unoccupied?](did-any-equipment-behave-differently-while-the-house-was-unoccupied.md) — **VISION — NOT YET ARCHITECTED**. Equipment can show a different pattern during an absence because demand, settings, weather or evidence coverage changed.
- [What should continue if the Internet goes down while we're away?](what-should-continue-if-the-internet-goes-down-while-we-re-away.md) — **VISION — NOT YET ARCHITECTED**. An Internet outage during an absence can affect remote visibility without necessarily stopping local equipment.
- [Are there sensitive details the housesitter should not receive?](are-there-sensitive-details-the-housesitter-should-not-receive.md) — **VISION — NOT YET ARCHITECTED**. A useful housesitter briefing can reveal much more than intended if it includes private histories, valuations or personal schedules.
