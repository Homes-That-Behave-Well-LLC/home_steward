# What should continue if the Internet goes down while we're away?

Status: VISION — NOT YET ARCHITECTED

## Household question

What should continue if the Internet goes down while we're away?

## Why it matters

An Internet outage during an absence can affect remote visibility without necessarily stopping local equipment. The household wants to understand those distinctions and existing arrangements in advance, not assume that a remote connection, cloud credential or intelligent fallback will remain available.

Source reports and inference are not automatic Truth; unknown is a valid result. No silent cloud or source fallback.
