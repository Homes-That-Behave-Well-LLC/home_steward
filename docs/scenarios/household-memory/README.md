# Household Memory

Navigation and scope guidance only; not an architecture contract or roadmap. Browse the [scenario-family map](../README.md).

## Purpose

Understand authorized stories, decisions and provenance without turning a Home into a continuous recording system.

## Relationship to HTBW

Authoritative originals, Foundation relationships, Truth history and owning HTBW histories remain distinct. Family provenance already has developed coverage. See the existing [HTBW boundary](../../architecture/htbw-boundary.md).

## Possible Home Steward extension

Retrieve and contextualize voluntarily supplied, independently permitted recollections and source records. Any new source admission, representation, handoff or implementation is an OPEN ARCHITECTURAL QUESTION.

## Boundaries

No new accepted memory/history responsibility or store, continuous recording, invented recollection or indefinite shadow narrative. Disputed memories, corrections, revocation, expiry and source-derived lifecycle remain binding.

Person/source/purpose/namespace/audience scope, household-controlled locality and source-derived lifecycle remain independent requirements. Potential evidence is not admitted access; knowledge is not action or disclosure authority. Source reports and inference are not automatic Truth; unknown is valid and correlation is not causation.
