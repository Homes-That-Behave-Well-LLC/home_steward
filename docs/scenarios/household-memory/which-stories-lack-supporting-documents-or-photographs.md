# Which stories lack supporting documents or photographs?

Status: VISION — NOT YET ARCHITECTED

## Household question

Which stories lack supporting documents or photographs?

## Why it matters

Some household stories are supported by photographs or documents, while others are meaningful recollections with no surviving corroboration. The household wants to understand that distinction without treating undocumented memories as worthless or false. A gap in the authorized sources is not proof that evidence never existed, and conflicting accounts should remain visibly attributed.

Not continuous recording or a new accepted memory/history responsibility. Preserve dates, scope, version and retention; corrected/disputed recollection is distinct from Facts. Derived-source revocation/expiry prohibit shadow memory.
