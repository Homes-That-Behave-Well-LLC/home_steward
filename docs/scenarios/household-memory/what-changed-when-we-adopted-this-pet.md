# What changed when we adopted this pet?

Status: VISION — NOT YET ARCHITECTED

## Household question

What changed when we adopted this pet?

## Why it matters

Adopting a pet can coincide with changes in room use, care routines or household preferences. The household wants to explore voluntarily documented changes and shared recollections without assuming the pet caused every difference. A meaningful account should preserve dates, other events and differing memories rather than becoming a continuous record of household behavior.
