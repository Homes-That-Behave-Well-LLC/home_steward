## Public Framework relationship

The common Framework remains the source of the governance approach. **Resolved at the repository level
by DL-153 (2026-11-10):** the BehavesWell Framework has **six stages** (Truth, Identity, Operational
Trust, Stewardship, Continuity, Concierge), and Foundation is **Layer 0** of a BehavesWell Core
implementation, not a seventh stage. The earlier six-versus-seven discrepancy is therefore closed for
this repository. Public stage-definition wording remains open at
[Core #215](https://github.com/Homes-That-Behave-Well-LLC/homes_that_behave_well/issues/215).
See [Framework relationship](../architecture/behaves-well-framework-relationship.md).
