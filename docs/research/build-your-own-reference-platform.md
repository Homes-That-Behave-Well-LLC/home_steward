## Possible component roles (inference, not a selected stack)

Governed private-AI host -> [inference](direct-llama-cpp-vllm.md), [Ollama](ollama.md) or
[Model Runner](docker-model-runner.md) -> retrieval/application layer such as
[AnythingLLM](anythingllm.md), [Dify](dify.md) or [Open WebUI](open-webui.md) -> scoped adapters ->
HTBW contract. This is an illustrative composition, not proof that those combinations interoperate.

No hardware/OS/provider/model/vector store/RAG/agent/container is selected or configured.
Original sources remain source-owned; platform replacement must not erase Home relationships.

## Control baseline must measure

Source/Person/derived scope, local-only enforcement, auth/tools, export/erase/restore, household
answer quality, coding-inference quality, context/concurrency, 24x7 stability, noise/power and maintainability.
Run the same accepted hard gates as appliances; open source alone does not prove privacy/security.

## Five-year TCO

Cash: acquisition/upgrades, power, storage/backups, licenses/cloud services if separately permitted,
support and exit. Owner time: build, integration, configuration, patching/security, monitoring,
backup/restore exercises, troubleshooting and eventual migration. Record hours and an explicit
valuation; Owner time is not free. No assumed free labor or calculated cost total.
