## Claims and unknowns

"Local-first" is a project description, not tested default egress. Desktop and server permission
models must not be assumed identical. Fine-grained API/MCP, account/source/person isolation, retrieval
filters, export, derived-memory revocation, telemetry and backup behavior were not established in
this bounded review.

Potential commodity application layer, not replacement Assist/Concierge or HTBW source of Truth.
Its full chat UI need not become a household-facing surface.
